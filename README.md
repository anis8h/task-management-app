# 🕷️ Task Management App

A modern, responsive Task Management Web Application built using **HTML, CSS, and JavaScript**.

The application helps users create, organize, track, search, filter, sort, and manage daily tasks with persistent browser storage.

## 🚀 Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📅 Add due dates
* 🔴 Automatic overdue detection
* ⚡ Task priority management
* 📂 Task categories
* 🔍 Search tasks
* 🎯 Filter tasks
* 🔄 Smart task sorting
* 📊 Task statistics dashboard
* 📈 Task completion progress
* 🧹 Clear completed tasks
* 💾 LocalStorage data persistence
* 📥 Export tasks as JSON
* 📤 Import tasks from JSON
* ⌨️ Keyboard shortcuts
* 🌙 Dark/Light mode
* 📱 Responsive mobile design
* ✨ Smooth animations and UI effects

## 🛠️ Technologies Used

* LocalStorage

* Responsive Web Design

## 💡 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing tasks.

No backend or database setup is required.

## 💾 Data Storage

Tasks are stored in the browser using **LocalStorage**.

The application also provides:

* JSON Export for backup
* JSON Import for restoring tasks

## 📱 Responsive Design

The application is designed to work on:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 🎯 Key Highlights

### Smart Task Management

Tasks can be organized using priority, category, due date, completion status, search, filters, and sorting.

### Automatic Overdue Detection

Tasks with past due dates are automatically identified as overdue.

### Progress Tracking

The dashboard displays total, pending, completed, and overdue tasks along with overall completion progress.

### Data Backup

Users can export their tasks as a JSON file and import them later.
